# IMSCAP architecture

The implemented direction is TAS -> Diameter Ro -> IMSCAP -> CAP v2 -> CAMEL SCP.

See [the IMSCAP profile](imscap-profile.md) for the implemented state machine, simulation boundaries, AVP policy and remaining transport, durability and availability work.

The [previous architecture](legacy-architecture.md) describes the earlier opposite-direction prototype. Its storage/runtime code remains available but is not connected to IMSCAP.
